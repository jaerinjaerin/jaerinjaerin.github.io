# CS Learning Lab

컴퓨터공학을 쉽게 들어가 깊게 배우는 인터랙티브 학습 사이트 — https://jaerinjaerin.github.io/

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run build    # dist/ 에 정적 사이트 생성
```

main 브랜치에 push하면 GitHub Actions가 빌드해 GitHub Pages에 배포합니다.
구조와 작성 규칙은 [docs/site-architecture.md](docs/site-architecture.md)를 참고하세요.
